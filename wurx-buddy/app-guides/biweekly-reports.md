## What this page is for
Brand reports that cover a 14-day period instead of one week. Open it from **Reporting → Bi-Weekly Reports**. It works almost exactly like Weekly Reports; this guide lists only the differences.

## Who can use it
Same split as Weekly Reports:
- **APC, IPC, PCTL, TL** get the "your brands" overview with **New Bi-Weekly Report**; TLs also see **Needs My Review**.
- **OL and Boss** get the organisation-wide list. Only the **OL** gets **Verify as TL**, **Approve**, **Return to TL**, **Reopen to Edit**, **Send Back to TL / APC** and **Submit as APC**. The Boss gets **Edit Dates** and **Delete report**.

## How to write and submit a bi-weekly report
1. Click **New Bi-Weekly Report** and pick the brand.
2. First bi-weekly report for a brand: choose **Starting Date of Period 1**, then **Confirm Starting Period & Begin Report**. Each later period starts 14 days after the previous one.
3. Fill the sections. **Generate All Insights** writes AI insights for the sections; check them before submitting.
4. **Save Draft** or **Submit Report**. The review chain is the same as weekly: APC submits → TL **Verify** (or **Return to APC** with a reason) → OL **Approve** (or **Return to TL**).

## Differences from Weekly Reports
- Periods are 14 days, labelled by period, not week.
- No **Auto Generate from Euka** and no **Import from PDF** buttons.
- **Change Period** appears in the editor for anyone editing an existing report (weekly limits **Change Week** to the OL).
- On the OL/Boss list, **Delete report** is Boss-only, and there are no **Notify APCs / Notify TLs** reminder buttons. Filters are in a filter popover (Brand, Team, Reporter, Period, Status) plus brand search.
- The "one report per period" and "previous report must be verified first" submit blocks apply to APCs only.

## Rules & gotchas
- Status flow, return notes, star ratings and the TL's optional mark deduction work the same as weekly.
- Once submitted, an APC can't edit until the report is sent back.
- Clients only see an approved report after an OL/Boss ticks **Share with client** on the brand's Reports tab.
